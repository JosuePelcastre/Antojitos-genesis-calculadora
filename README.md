# Antojitos-genesis-calculadora
punto de venta móvil sencillo para la gestión de pedidos y el cálculo de importes.

# Descripción

Aplicación web desarrollada para apoyar las ventas del negocio de antojitos de nuestra iglesia. Permite sumar los precios de los productos seleccionados y alternar entre precios normales y precios de media orden.

# Tecnologías

* HTML5

* CSS3

* JavaScript
